# WeChat & Media Tools (一站式多平台媒体下载与管理工具)

[![Release](https://img.shields.io/github/v/release/x554960766/wechatAutoRSSTool?style=flat-square)](https://github.com/x554960766/wechatAutoRSSTool/releases)
[![License](https://img.shields.io/github/license/x554960766/wechatAutoRSSTool?style=flat-square)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-macOS%20%7C%20Windows-blue?style=flat-square)](#)

本地运行的多平台内容离线下载与归档工具，支持 **微信公众号、视频号、抖音、快手、小红书、哔哩哔哩** 资源批量下载、RSS 订阅及音视频转码。支持原生桌面窗口（`pywebview`）与浏览器 Web 模式。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。请直接前往 [👉 GitHub Releases 下载最新版本 (v2.2.3)](https://github.com/x554960766/wechatAutoRSSTool/releases)。

### 📦 安装包版本说明（Full 完整版 vs Lite 精简版）

在 [GitHub Releases 发布页面](https://github.com/x554960766/wechatAutoRSSTool/releases) 中，每个系统平台均提供了 **Full（完整版）** 与 **Lite（精简版）** 两个打包安装包，二者业务功能完全一致，区别在于是否内置独立的浏览器内核：

| 对比维度 | 🌟 Full (完整版) | ⚡ Lite (轻量精简版) |
| :--- | :--- | :--- |
| **压缩包体积** | 约 **200 MB ~ 240 MB** | 约 **40 MB ~ 60 MB**（体积小，极速下载） |
| **内置浏览器** | **内置独立专用的 Chromium 浏览器核心** | **不内置浏览器内核**，安装包极为精炼 |
| **外部运行依赖** | **零外部依赖**。电脑上无需安装任何浏览器即可开箱即用 | **依赖系统浏览器**（需要电脑已安装 Google Chrome 或 Microsoft Edge） |
| **防风控与无头渲染** | 使用内置独立纯净浏览器沙盒，不受外部浏览器更新与配置干扰 | 运行时自动探测并接管调用本机已安装的 Chrome / Edge 浏览器 |
| **推荐适用人群** | **强烈推荐大多数用户 / 电脑环境较干净的用户使用**，最省心稳定 | **电脑已装有 Chrome/Edge、追求小体积与快速下载的用户** |

## 核心功能

### 📱 微信公众号
> 💡 **很多同类开源项目已陆续闭源转向收费，本项目坚持开源并已完整支持公众号历史文章列表获取，且用且珍惜！**
- **移动端会话激活与保活协议**：逆向微信读书移动端同步协议（`AppService.mobileSync`），在用户扫码登录及接口凭证拦截后自动建立有效终端同步态，彻底攻克 `/mp/chapters` 章节获取与 `store/search` 搜索频繁遭遇的 **499 (-2041)** 频控阻断。
- **书架与关注公众号多源聚合体系**：全面打通 `weread_web` 多源抓取、官方书架推文同步（`/shelf/sync?synckey=0`）、`/mp/list`（listType 0 与 1）以及订阅列表（`/subscription/books`），彻底解决历史关注公众号丢失、搜索不到及列表展示不全的问题。
- **推文多级平滑降级与原生链接并发解析**：构建「`mp/chapters` -> 置顶推文解析 -> `article/list` 备用拉取」多通道容灾链，全链路并发解析并补齐文章原生微信永久链接（`doc_url`）与去重。
- **多格式高保真离线导出**：支持完整保存原文排版的 HTML（含图片/音视频本地化）、适配 Obsidian/Notion 的语义 Markdown，以及高精度矢量 PDF 导出。
- **RSS 订阅与增量同步**：内置标准 RSS 2.0 服务，为每个公众号生成专属 Feed 订阅链接，支持各类阅读器订阅及后台定时增量同步。

### 🎥 微信视频号
- **单视频解析下载**：粘贴分享链接即可快速解析并无水印下载视频。
- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。

### 🎵 抖音
- **纯 Python SecSDK 签名算法**：完整移植并实现 `x-secsdk-web-signature` 与 `uifid` 动态校验绑定，从底层杜绝抖音 Web 端的 Argus 403 频控与鉴权拦截。
- **无水印视频、图集与实况照片解析**：支持单视频、高清图集及 Live Photo 实况照片（原图 + `_live.mp4` 动态短视频 + 原生 BGM）一键无水印下载，提供直链提取、文案复制及音频提取。
- **评论深度抓取与结构化导出**：支持单视频全量/限量抓取，完整保留一级主评与二级楼中楼回复，支持自定义条数并导出为 JSON，自动与视频同目录归档。
- **作者主页与批量采集**：支持收藏创作者，一键拉取作者主页全部作品批量下载，支持增量采集与自动去重。
- **喜欢与全能收藏体系**：支持批量下载个人（含私密）与公开博主的喜欢列表，支持全部收藏单视频、分类收藏夹及合集播单（collectmix）。
- **直播间与回放解析**：支持抖音直播间实时解析（状态/清晰度/主播信息）以及历史直播回放列表采集。

### ⚡ 快手
- **高清视频解析下载**：支持快手单视频、图集无水印解析与批量采集。
- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书
- **单篇笔记解析**：支持粘贴小红书图文/视频链接，无水印下载高清图片、视频及 Live 实况图，导出文案文本与离线网页。
- **智能视频流挑选与容灾**：自动优先挑选通用兼容性最佳的 H.264 编码最高清视频轨，支持多候选 CDN 自动重试降级下载。
- **博主主页深度采集**：支持 SSR 状态与页面 DOM 智能混合提取首屏笔记，配合网络接口拦截与物理滚动，完整采集博主所有笔记作品。

### 📺 哔哩哔哩
- **单视频与多分P下载**：支持 BV/AV 号、番剧及多分P视频解析，批量下载指定分P。
- **UP主空间投稿采集**：收藏 UP 主或输入空间链接，一键获取投稿列表并批量下载。
- **音视频无损混流**：自动下载最高清画质音视频轨，并使用本地 FFmpeg 自动混流为完整 MP4。
- **弹幕与字幕提取**：支持将弹幕转为 ASS 格式，支持提取 CC 字幕并转为 SRT/ASS 格式。

### 🎬 视频转码与空间优化
- **全格式兼容**：支持 MP4、MKV、MOV、WebM、AVI、FLV、TS 等视频格式互转，以及提取 MP3 音频。
- **一键智能扫描**：自动递归扫描微信视频号与抖音所有已下载媒体，支持一键批量转码与拖拽导入。
- **硬件加速与压缩比对**：支持 H.264/H.265 编码与硬件加速，实时计算转码前后体积比对与空间节省百分比。
- **环境自愈**：自动探测加载系统与内置 FFmpeg 环境，缺失时支持一键自动下载配置。

## 微信公众号使用指引

1. **添加公众号**：复制任意一篇公众号文章链接，在「公众号」页面粘贴并点击添加，自动获取公众号信息建档；
2. **文章导出**：支持单篇直接输入链接下载，或在公众号详情页按时间范围/篇数批量拉取，导出 HTML、Markdown、PDF 格式；
3. **RSS 订阅**：在公众号详情页点击「RSS」获取订阅链接，可直接添加至各类 RSS 阅读器。

## 本地运行与二次开发

如果你需要直接运行源码或进行二次开发：

```bash
# 1. 克隆代码
git clone https://github.com/x554960766/wechatAutoRSSTool.git
cd wechatAutoRSSTool

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium

# 3. 启动应用
python3 main.py   # 桌面端模式（基于 pywebview 原生窗口）
# 或
python3 app.py    # 浏览器模式（访问 http://localhost:5200）
```
