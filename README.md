# 微信公众号 / 视频号 / 抖音 / 快手 / 小红书 / 哔哩哔哩 下载与转码工具箱

一个本地运行的一站式多平台内容下载与管理工具，支持微信公众号、视频号、抖音、快手、小红书、哔哩哔哩资源离线下载、RSS 订阅及视频转码。

支持桌面应用原生窗口（`pywebview`）运行，也可作为 Web 服务在浏览器中访问。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。请直接前往 [👉 GitHub Releases 下载最新版本 (v2.0.0)](https://github.com/x554960766/wechat-mp-tools/releases)。

### macOS 版本选择

| Mac 类型 | 下载版本 |
|----------|----------|
| **Apple Silicon**（M1/M2/M3/M4 芯片） | `ARM64` 系列产物 |
| **Intel** 芯片 | `x86-64` 系列产物 |

如果不确定自己的芯片类型，点击屏幕左上角  &#x1F5A5;  →「关于本机」即可查看。ARM64 产物无法在 Intel Mac 上运行，x86-64 产物虽然可以通过 Rosetta 在 Apple Silicon 上运行，但推荐使用原生 ARM64 版本以获得最佳性能。

## 核心功能

### 📱 微信公众号（v2.0.0 重点升级）

- **全格式离线保存与导出**：
  - **原生 HTML 离线归档**：完整保存微信原文样式排版，自动将高清原图、音频（Voice）、视频（Video）下载至本地并完成相对路径改写；针对微信特殊的画廊图集（Gallery）与特殊贴图排版均能完整提取与解析。
  - **Markdown 结构化导出**：深度解析文章语义结构，完整保留大纲标题、作者、公众号信息、发布时间、粗体/斜体/删除线、代码块（含语言标签）、引用区块、列表与数据表格，正文图片与封面图自动映射为本地相对路径，完美适配 Obsidian、Logseq、Notion 等知识库体系。
  - **高保真 PDF 导出**：自动探测并调用本地 Chromium / Chrome / Edge 渲染引擎，执行 Headless 打印导出高精度矢量 PDF，排版规整，适合长效阅读与纸质打印。
  - **标准元数据**：每篇下载的文章均自动生成配套的 `metadata.json`，记录标题、作者、发表时间戳、原文 URL、摘要及本地文件索引。
- **多维度公众号管理与批量采集**：
  - **链接智能解析**：只需粘贴公众号任意一篇文章链接，系统自动解析并提取 `__biz`、公众号名称与头像，一键快速添加并建档。
  - **历史文章批量获取**：支持自由指定时间范围（开始日期 ~ 结束日期）或指定篇数精确筛选文章；提供分页拉取、增量同步与断点续传机制，已下载内容自动去重跳过。
  - **批量“聚合页”流转采集引擎**：针对批量公众号刷新场景，自动唤起客户端内置「公众号授权聚合中心」并保持常驻，在后台逐个激活各公众号卡片并毫秒级捕获该号专属凭据，快速获取最新文章列表。
- **双模凭证体系与高可用自动化**：
  - **方案 A：微信读书免密扫码账号池（推荐，无客户端依赖）**：
    - 页面直接生成微信扫码登录二维码，手机扫码即可极速授权。
    - **多账号池轮询**：支持同时绑定多个采集账号，系统多线程自动轮询调度，避免单账号高频请求触发风控。
    - **TLS 浏览器指纹模拟**：底层基于 `curl_cffi` 完整模拟现代浏览器 TLS 握手特征，杜绝特征识别与握手拦截。
    - **会话持久化与深度保活**：支持独立 Playwright Profile 隔离与无感自动保活换新；具备 Verify-First 智能探活机制，遇 429 频率限制自动避让并自愈恢复，失效账号自动熔断。
  - **方案 B：PC 微信客户端自动化与 MITM 代理（支持私密专属凭据）**：
    - 内置本地安全 MITM 代理服务，毫秒级静默拦截 PC 微信客户端请求，自动提取并写入 `key`、`pass_ticket`、`appmsg_token`、`uin` 等短时效核心凭证。
    - **Windows 客户端自动化**：基于 Win32 API / UIA 驱动，采用后台合成消息（`PostMessage`）模式，**完全不抢夺用户鼠标焦点**，静默定位、触发刷新并毫秒级异步关闭弹窗。
    - **macOS 客户端自动化**：基于 AppleScript 与系统原生 Vision OCR 智能窗口定位与聚合页流转，全程平滑无感。
    - **安全隐私脱敏**：内置 `cred_redact` 模块，对外控制台与日志中所有敏感 token/key 参数统一掩码脱敏，完整数据仅在本地私有账号池加密保存。
- **RSS 订阅与自动增量更新**：
  - 内置标准 RSS 2.0 服务端，为每个公众号生成独立的专属订阅链接（Feed）。
  - 支持直接接入 NetNewsWire、Follow、Inoreader、Feedly、Reeder 等主流阅读器。
  - 支持自定义定时自动增量抓取，新文章发布自动入库并同步 RSS 输出。

- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。

### 🎵 抖音
- **单视频与图集无水印解析**：支持单条视频与图集内容一键无水印下载，提供直链提取、新标签页播放与文案一键复制。
- **喜欢/点赞列表智能穿透**：
  - 支持查看与批量下载当前登录账号的点赞视频，即使喜欢列表设置为「仅自己可见（私密）」亦可无感获取。
  - 支持输入任意公开博主的 `sec_uid` 或主页链接，一键获取他人公开点赞列表。
  - 支持物理滚动无限翻页采集与本地增量去重。
- **全能收藏体系 (`collect` & `collectmix`)**：
  - **全部收藏单视频**：直接拉取个人全部收藏视频列表。
  - **分类收藏夹**：支持获取自定义收藏夹分类列表及每个收藏夹下的专属视频。
  - **收藏合集列表**：支持获取已收藏的合集/播单列表（`collectmix`）。
- **双通道风控自愈机制**：
  - 针对抖音 `ArgusSecurityPlugin` 动态 `uifid` 与 `x-secsdk` 风控拦截，实现「HTTP 直连 + Playwright 会话沙箱」自动容灾自愈降级，100% 稳定穿透。
  - 扫码登录自动初始化个人主页与收藏会话，全自动提取与同步新鲜安全凭证。
- **直播间与回放解析**：支持抖音直播间实时解析（状态、清晰度列表、主播信息）以及博主历史直播回放列表采集。
- **搜索博主信息增强**：多线程并发补全搜索结果中的博主作品数、粉丝数与获赞数据。

### ⚡ 快手
- **高清视频解析下载**：支持快手单视频、图集无水印解析与批量采集。
- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书
- **单篇笔记解析**：支持粘贴小红书图文/视频链接，无水印下载高清图片、视频及 Live 实况图，导出文案文本与离线网页。
- **智能视频流挑选与容灾**：自动优先挑选通用兼容性最佳的 H.264 编码最高清视频轨，支持多候选 CDN 自动重试降级下载。
- **博主主页深度采集**：支持 SSR 状态与页面 DOM 智能混合提取首屏笔记，配合网络接口拦截与物理滚动，完整采集博主所有笔记作品。

### 📺 哔哩哔哩
- **单视频与多分P下载**：支持 BV/AV 号、番剧及多分P视频解析，批量下载指定分P。

### 🎬 视频转码与空间优化

- **硬件加速与压缩比对**：支持 H.264/H.265 编码与硬件加速，实时计算转码前后体积比对与空间节省百分比。
- **环境自愈**：自动探测加载系统与内置 FFmpeg 环境，缺失时支持一键自动下载配置。

## 微信公众号使用操作指引

### 1. 凭证配置（两种方式任选其一）

#### 方式一：微信读书扫码登录（推荐，轻量便捷）
1. 打开软件，进入左侧导航栏的 **「公众号管理」** 或 **「账号设置」** 页面；
2. 点击 **「添加微信读书账号」**，界面将实时显示登录二维码；
3. 打开手机微信扫一扫确认登录，系统将自动捕获凭证并纳入多账号轮询池；
4. 建议添加 2~3 个账号，系统会自动轮换调度，实现高频安全下载。

#### 方式二：PC 微信客户端自动抓包与续期（抓取历史所有文章必备）
1. 在设置页面开启 **「本地抓包代理」**（首次使用按界面指引一键信任本地根证书）；
2. 保持电脑端微信正常登录运行；
3. 点击 **「刷新凭证」** 或开启 **「后台自动续期」**：
   - **Windows 用户**：程序将自动通过后台消息指令刷新文章或唤起公众号聚合页，无需手动干预，也不抢占鼠标；
   - **macOS 用户**：程序将自动唤起前台交互流转并捕获凭证；
4. 抓包成功后，系统即自动提取当前公众号的专属凭据并更新至账号池。

### 2. 添加公众号
1. 打开任意一篇想保存的微信公众号文章，复制文章链接；
2. 在软件 **「公众号」** 页面顶部的输入框中粘贴链接，点击 **「添加公众号」**；
3. 系统将自动解析公众号名称、头像及标识，并添加到管理列表中。

### 3. 下载与导出文章
1. **单篇下载**：在首页直接输入文章 URL，选择想要保存的格式（HTML / Markdown / PDF），点击「立即下载」即可快速保存；
2. **批量下载**：
   - 在公众号列表中点击目标公众号进入详情页；
   - 点击 **「获取文章列表」**，可设置抓取篇数或指定日期区间；
   - 勾选文章后点击 **「批量下载」**；
   - 下载完成后，点击 **「打开所在文件夹」** 即可查看下载保存的 HTML、Markdown 与 PDF 文件。

### 4. 配置 RSS 订阅
1. 在公众号详情或管理列表中，点击公众号对应的 **「RSS」** 图标，即可复制该号的标准 RSS 2.0 订阅链接；
2. 将链接粘贴至 NetNewsWire、Follow 等任意 RSS 阅读器即可；
3. 在软件设置中开启 **「自动定时同步」**，程序将按设定的周期自动增量抓取最新文章，无需人工守候。

## 本地运行与二次开发

如果你需要直接运行源码或进行二次开发：

```bash
# 1. 克隆代码
git clone https://github.com/x554960766/wechat-mp-tools.git
cd wechat-mp-tools

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium

# 3. 启动应用
python main.py   # 桌面端模式（基于 pywebview 原生窗口）
# 或
python app.py    # 浏览器模式（访问 http://localhost:5200）
```
