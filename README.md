# 微信公众号 / 视频号 / 抖音 / 快手 / 小红书 / 哔哩哔哩 下载与转码工具箱

一个本地运行的一站式多平台内容下载与管理工具，支持微信公众号、视频号、抖音、快手、小红书、哔哩哔哩资源离线下载、RSS 订阅及视频转码。

支持桌面应用原生窗口（`pywebview`）运行，也可作为 Web 服务在浏览器中访问。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。请直接前往 [👉 GitHub Releases 下载最新版本](https://github.com/x554960766/wechat-mp-tools/releases)。

---

## 核心功能

### 📱 微信公众号
- **文章离线下载**：支持输入公众号文章链接，完整保存正文排版（包含 HTML、高清图片、音频和视频等），支持画廊与贴图类特殊排版。
- **公众号管理**：粘贴公众号任意文章链接即可一键解析添加该公众号，浏览与按时间范围批量下载历史文章。
- **微信读书账号池与全自动深度保活**：
  - 页面直接扫码登录，无需弹出外部浏览器窗口。
  - 支持绑定多个采集账号，系统自动轮询调度。
  - **无头浏览器会话深度保活**：支持独立 Playwright Profile 会话隔离与自动后台无头换新（Plan B），保持凭证长效新鲜。
  - **智能容错自愈**：Verify-First 智能探活，遇频率限制（429）自动避让并自愈恢复，失效账号自动熔断。
- **RSS 订阅与自动同步**：支持为公众号开启定时自动增量拉取，并输出标准 RSS 2.0 Feed。

### 🎥 微信视频号
- **单视频解析下载**：粘贴分享链接即可快速解析并无水印下载视频。
- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。

### 🎵 抖音
- **单视频与图集无水印解析**：支持单条视频与图集内容一键无水印下载，提供直链提取、新标签页播放与文案一键复制。
- **多维度批量采集**：支持按用户主页、推荐流、搜索博主、喜欢列表和收藏夹进行批量下载。
- **直播间与回放解析**：支持抖音直播间实时解析（状态、清晰度列表、主播信息）以及博主历史直播回放列表采集。
- **搜索博主信息增强**：多线程并发补全搜索结果中的博主作品数、粉丝数与获赞数据。
- **扫码登录**：支持扫码登录获取 1080P/4K 高清画质内容。

### ⚡ 快手
- **高清视频解析下载**：支持快手单视频、图集无水印解析与批量采集。
- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书
- **单篇笔记解析**：支持粘贴小红书图文/视频链接，无水印下载高清图片、视频及 Live 实况图，导出文案文本与离线网页。
- **博主主页批量采集**：支持扫码登录后浏览博主主页笔记列表，支持翻页加载与一键批量勾选下载。

### 📺 哔哩哔哩
- **单视频与多分P下载**：支持 BV/AV 号、番剧及多分P视频解析，批量下载指定分P。
- **UP主空间投稿采集**：收藏 UP 主或输入空间链接，一键获取投稿列表并批量下载。
- **音视频无损混流**：自动下载最高清画质音视频轨，并使用本地 FFmpeg 自动混流为完整 MP4。
- **弹幕与字幕提取**：支持将弹幕转为 ASS 格式，支持提取 CC 字幕并转为 SRT/ASS 格式。

### 🎬 视频转码与空间优化
- **全格式兼容**：支持 MP4、MKV、MOV、WebM、AVI、FLV、TS 等视频格式互转，以及提取 MP3 音频。
- **一键智能扫描**：自动递归扫描微信视频号与抖音所有已下载媒体，支持一键批量转码与拖拽导入。
- **硬件加速与压缩比对**：支持 H.264/H.265 编码与硬件加速，实时计算转码前后体积比对与空间节省百分比。
- **环境自愈**：自动探测加载系统与内置 FFmpeg 环境，缺失时支持一键自动下载配置。

## 本地运行与二次开发

如果你需要直接运行源码或进行二次开发：

```bash
# 1. 克隆代码
git clone https://github.com/x554960766/wechat-mp-tools.git
cd wechat-mp-tools

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium

# 3. 启动应用
python main.py   # 桌面端模式（基于 pywebview 原生窗口）
# 或
python app.py    # 浏览器模式（访问 http://localhost:5200）
```

## 数据目录说明

- **macOS**：`~/Library/Application Support/WeChat MP Tools/data/`
- **Windows / Linux**：程序同级目录下的 `data/`
- 包含登录凭据、独立浏览器 Profile 缓存、收藏博主/公众号数据、下载历史记录及下载文件。
