# 微信公众号 / 视频号 / 抖音 / 快手 / 小红书 / 哔哩哔哩 下载与转码工具箱

一个本地运行的一站式多平台内容下载与管理工具，支持微信公众号、视频号、抖音、快手、小红书、哔哩哔哩资源离线下载、RSS 订阅及视频转码。

支持桌面应用原生窗口（`pywebview`）运行，也可作为 Web 服务在浏览器中访问。

> [!TIP]
> **开箱即用，无需配置本地 Python 开发环境！**
> 本项目已通过 GitHub Actions 自动构建 Windows 与 macOS 双平台客户端。请直接前往 [👉 GitHub Releases 下载最新版本 (v2.0.1)](https://github.com/x554960766/wechat-mp-tools/releases)。

### macOS 版本选择

| Mac 类型 | 下载版本 |
|----------|----------|
| **Apple Silicon**（M1/M2/M3/M4 芯片） | `ARM64` 系列产物 |
| **Intel** 芯片 | `x86-64` 系列产物 |

如果不确定自己的芯片类型，点击屏幕左上角  &#x1F5A5;  →「关于本机」即可查看。ARM64 产物无法在 Intel Mac 上运行，x86-64 产物虽然可以通过 Rosetta 在 Apple Silicon 上运行，但推荐使用原生 ARM64 版本以获得最佳性能。

## 核心功能

### 📱 微信公众号（v2.0.1 核心引擎全面升级）

- **全格式离线保存与导出**：
  - **原生 HTML 离线归档**：完整保存微信原文样式排版，自动将高清原图、音频（Voice）、视频（Video）下载至本地并完成相对路径改写；针对微信特殊的画廊图集（Gallery）与特殊贴图排版均能完整提取与解析。
  - **Markdown 结构化导出**：深度解析文章语义结构，完整保留大纲标题、作者、公众号信息、发布时间、粗体/斜体/删除线、代码块（含语言高亮标签）、引用区块、列表与数据表格，正文图片与封面图自动映射为本地相对路径，完美适配 Obsidian、Logseq、Notion 等知识库体系。
  - **高保真 PDF 导出**：自动探测并调用本地 Chromium / Chrome / Edge 渲染引擎，执行 Headless 打印导出高精度矢量 PDF，排版规整，适合长效阅读与纸质打印。
  - **标准元数据**：每篇下载的文章均自动生成配套的 `metadata.json`，记录标题、作者、发表时间戳、原文 URL、摘要及本地文件索引。
- **PC 微信智能交互与原生自动化（跨平台支持）**：
  - **内置安全 MITM 拦截代理**：本地自动管理证书与代理路由，毫秒级静默截获 PC 微信发起的文章与公众号请求，自动提取并写入 `key`、`pass_ticket`、`appmsg_token`、`uin` 等短时效核心凭证。
  - **Windows 原生无感自动化（Win32 API / UIA）**：
    - 基于底层的 `PostMessage` 消息投递机制，**完全不抢占真实鼠标、不夺取系统输入焦点**；
    - 支持后台刷新已有文章窗口、自动定位「订阅号消息」，秒级异步关闭弹出的原生公众号名片；
    - 真正做到在系统后台静默工作，不打扰用户的正常办公与游戏使用。
  - **macOS 原生自动化（AppleScript + Vision OCR）**：
    - 基于系统原生 Vision OCR 高精度中英文字符识别与 AppleScript 智能定位微信窗口，全自动完成页面流转与凭证刷新。
  - **批量“聚合页”流转采集引擎**：
    - 针对多公众号更新场景，自动唤起微信客户端内置「公众号批量授权聚合中心」并保持常驻；
    - 在后台逐个激活各公众号卡片并毫秒级捕获该号专属凭据，快速获取最新文章列表。
  - **智能刷新队列与敏感凭证脱敏**：
    - 内置后台刷新队列（`refresh_queue`），具备去重冷却（Dedup Cooldown）、自愈重试与防死循环退避机制；
    - 内置安全隐私脱敏模块（`cred_redact`），控制台与日志中所有敏感 token/key 参数统一掩码脱敏，完整凭证仅在本地账号池中安全保存。
- **多维度公众号管理与批量采集**：
  - **链接智能解析**：只需粘贴公众号任意一篇文章链接，系统自动解析并提取 `__biz`、公众号名称与头像，一键快速添加并建档。
  - **历史文章批量获取**：支持自由指定时间范围（开始日期 ~ 结束日期）或指定篇数精确筛选文章；提供分页拉取、增量同步与断点续传机制，已下载内容自动去重跳过。
- **RSS 订阅与自动增量更新**：
  - 内置标准 RSS 2.0 服务端，为每个公众号生成独立的专属订阅链接（Feed）。
  - 支持直接接入 NetNewsWire、Follow、Inoreader、Feedly、Reeder 等主流阅读器。
  - 支持自定义定时自动增量抓取，新文章发布自动入库并同步 RSS 输出。

- **博主作品采集**：支持收藏博主、获取作者主页作品列表，支持一键批量下载。
- **关注列表一键增量采集**：一键同步并增量采集所有已关注博主的作品，自动跳过已下载内容。
- **本地历史自动同步**：自动扫描本地已下载文件，智能补全下载历史记录。

### 🎵 抖音
- **单视频与图集无水印解析**：支持单条视频与图集内容一键无水印下载，提供直链提取、新标签页播放与文案一键复制。
- **喜欢/点赞列表智能穿透**：
  - 支持查看与批量下载当前登录账号的点赞视频，即使喜欢列表设置为「仅自己可见（私密）」亦可无感获取。
  - 支持输入任意公开博主的 `sec_uid` 或主页链接，一键获取他人公开点赞列表。
  - 支持物理滚动无限翻页采集与本地增量去重。
- **全能收藏体系 (`collect` & `collectmix`)**：
  - **全部收藏单视频**：直接拉取个人全部收藏视频列表。
  - **分类收藏夹**：支持获取自定义收藏夹分类列表及每个收藏夹下的专属视频。
  - **收藏合集列表**：支持获取已收藏的合集/播单列表（`collectmix`）。
- **双通道风控自愈机制**：
  - 针对抖音 `ArgusSecurityPlugin` 动态 `uifid` 与 `x-secsdk` 风控拦截，实现「HTTP 直连 + Playwright 会话沙箱」自动容灾自愈降级，100% 稳定穿透。
  - 扫码登录自动初始化个人主页与收藏会话，全自动提取与同步新鲜安全凭证。
- **直播间与回放解析**：支持抖音直播间实时解析（状态、清晰度列表、主播信息）以及博主历史直播回放列表采集。
- **搜索博主信息增强**：多线程并发补全搜索结果中的博主作品数、粉丝数与获赞数据。

- **流式断点续传与重试自愈**：支持网络异常中断自动重试与 Range 断点续传，保障大文件下载稳定可靠。

### 📕 小红书

- **博主主页深度采集**：支持 SSR 状态与页面 DOM 智能混合提取首屏笔记，配合网络接口拦截与物理滚动，完整采集博主所有笔记作品。

## 微信公众号使用操作指引

### 1. 凭证配置与初始化（PC 微信极速就绪）
1. **安装本地根证书**：首次使用进入软件左侧「设置」页面，点击 **「安装证书」**（系统会自动安装并信任本地安全抓包根证书）；
2. **开启本地抓包代理**：点击开启 **「本地抓包代理」** 开关；
3. **保持电脑端微信登录运行**；
4. **获取/刷新凭证**（任选以下任一方式）：
   - **方式一（一键自动刷新）**：在「公众号」或「账号设置」页面点击 **「刷新凭证」** 或开启 **「定时自动同步」**，程序将自动通过 Windows 后台消息合成（不抢鼠标）或 macOS 原生窗口流转，毫秒级提取并更新最新凭据；
   - **方式二（手动触发）**：在电脑端微信中随意点击打开任意一篇公众号文章，程序内置的 MITM 代理将自动捕获请求并在后台静默提取凭证。

### 2. 添加公众号
1. 在微信中打开任意一篇想抓取的公众号文章，复制其文章链接；
2. 打开软件 **「公众号」** 页面，在顶部链接输入框中粘贴该文章链接，点击 **「添加公众号」**；
3. 系统将自动解析公众号的 `__biz`、名称、头像等信息，并添加到公众号管理列表中。

### 3. 下载与全格式导出文章
1. **单篇快速下载**：
   - 在首页直接粘贴单篇文章 URL；
   - 勾选所需保存的格式：**HTML**、**Markdown**、**PDF**；
   - 点击 **「立即下载」** 即可高速保存。
2. **历史文章批量下载**：
   - 在公众号列表中点击目标公众号进入详情页；
   - 点击 **「获取文章列表」**，可自定义获取篇数，或通过起止日期选择特定时间范围；
   - 勾选目标文章，点击 **「批量下载」**；
   - 下载完成后点击 **「打开所在文件夹」**，即可查阅保存的原生 HTML 页面、Markdown 结构化文档与高精度 PDF 归档文件。

### 4. 配置 RSS 订阅与自动增量更新
1. 在公众号详情页或公众号管理列表中，点击对应的 **「RSS」** 按钮，即可复制该公众号专属的标准 RSS 2.0 订阅链接；
2. 将链接添加到 NetNewsWire、Follow、Inoreader 等任意 RSS 阅读器中；
3. 在软件「设置」中开启 **「自动定时同步」**，程序将在后台按设定的间隔周期自动抓取增量文章，并实时更新至 RSS Feed。

## 本地运行与二次开发

如果你需要直接运行源码或进行二次开发：

```bash
# 1. 克隆代码
git clone https://github.com/x554960766/wechat-mp-tools.git
cd wechat-mp-tools

# 2. 安装依赖
pip install -r requirements.txt
playwright install chromium

# 3. 启动应用
python main.py   # 桌面端模式（基于 pywebview 原生窗口）
# 或
python app.py    # 浏览器模式（访问 http://localhost:5200）
```
